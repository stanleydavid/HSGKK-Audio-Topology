# X18 Bus 1 — AWL IEM

**Send mode:** Pre-fader.

Recommended starting mix:

| Ch | Source | Send |
|---:|---|---:|
| 1 | Shure Wireless 1 — Speaker | -15 dB |
| 2 | Shure Wireless 2 — WL | -6 dB |
| 3 | AWL Vox 1 | -3 dB |
| 4 | AWL Vox 2 | -3 dB |
| 5 | AWL Vox 3 | -3 dB |
| 6 | MD Key/Bass/Gtr | -8 dB |
| 7 | PA Mic | -12 dB |
| 8 | PreSonus Band | -8 dB |
| 9 | Additional Wireless | -12 dB |

Priority: **AWL vocals > WL > MD/Band > PA/Speaker/reference wireless**.

This is a shared AWL starting mix. If Bus 1 later becomes dedicated to one singer, raise that singer relative to the other AWLs rather than preserving equal Ch 3/4/5 levels.
